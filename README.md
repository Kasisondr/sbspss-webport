# sbspss-webport

SpongeBob SquarePants: SuperSponge ported to the web.

## Overview

* **Native Execution:** Runs the original PlayStation 1 version of the game natively without an emulator.
* **High Performance:** Achieves 60+ frames per second on almost any device.
* **Lightweight:** The core build is only 30 MB.
* **Controls:** Full gamepad support included.
* **Status:** Early release; minor bugs may be present.

---

## Getting Started

Because GitHub has limitations on large file uploads, the required game data file must be downloaded separately.

1. Download the required data file: [MediaFire - game.data](https://www.mediafire.com/file/3qkg481mtgbraas/game.data/file)
2. Place the `game.data` file into the appropriate directory in your project setup.
